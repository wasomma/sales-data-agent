# Sample data — SYNTHETIC ONLY

Reference copies of the generated demo dataset, committed for easy viewing and
demonstrations. **The agent does not read this folder** — it only ingests from
`data/inbox/` (git-ignored).

| File | Contents |
|---|---|
| `sales_pipeline_2026-06-30.xlsx` | Pipeline snapshot #1 — 120 deals, $24.0M |
| `sales_pipeline_2026-07-21.xlsx` | Snapshot #2, three weeks later — 128 deals, $25.9M, with stage/date/amount drift |
| `qbr_deck_2026-07-21.pptx` | QBR deck with narrative slides and an embedded top-10 deals table |

Everything here is generated by `sales generate-sample`
(`src/sales_agent/generate.py`, seeded RNG) — accounts, deals, and people are
fictional. Deleting this folder loses nothing; it can be regenerated exactly.

> ⚠️ **Never place real company exports in this folder.** It is exempted from
> the repository's spreadsheet/deck ignore rules, so anything put here WILL be
> committed and pushed. Real data belongs in `data/inbox/`, which git ignores.
